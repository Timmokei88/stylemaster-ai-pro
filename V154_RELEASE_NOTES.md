# MixoLabs V154

- Owner Settings now contains the music-generation on/off control and its credit rate.
- The main prompt offers **AI Image** and **AI Video** modes.
- Direct text-to-video no longer requires creating an image first.
- Optional uploaded reference images are used as identity references for direct video.
- Video length supports every whole second from 5 through 60.
- Video cost is calculated per started five seconds and controlled by the owner.
- Video supports 16:9, 9:16, 1:1, 4:5, 5:4, 3:2, 2:3 and 21:9.
- Image-to-video prompting includes strict face, cast, species, costume and role continuity rules.
- Failed provider video jobs retain the existing automatic credit-refund protection.

## Important accuracy note

The continuity brief materially strengthens the provider request, but no generative video model can truthfully guarantee zero face drift or character substitution in every output. Use a clear reference image for the strongest identity preservation. Failed requests are refunded; a completed but imperfect artistic result is not automatically classified as a technical failure.
