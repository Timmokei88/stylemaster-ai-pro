# MixoLabs V80 — Automatic CAD measurements

CAD & Blueprint Tools now provides three measurement methods:

- **Manual:** uses only measurements entered by the creator and marks missing values as not specified.
- **Automatic:** follows the description and object type, generates a coherent conceptual measurement set in the chosen unit, and visibly labels every number as estimated.
- **Proportions only:** produces a technical concept without numerical dimensions.

Object types include automatic detection, boats/marine craft, road vehicles, aircraft/drones, buildings, furniture, consumer products, machines, enclosures and other technical objects. Each type receives an appropriate dimension checklist. For example, the boat profile requests length, beam, height, hull depth, draft, transom width, deck/cabin envelope, seating clearances and propulsion locations.

Automatic measurements are conceptual AI estimates. They are not certified specifications and must be professionally checked before fabrication, construction or safety-critical use.
