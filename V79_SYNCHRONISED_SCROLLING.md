# MixoLabs V79 — Smoother synchronised scrolling

- The left Generator Settings scrollbar and main/right studio scrollbar now move together proportionally on desktop.
- Scrolling either panel near the top settles both at the prompt description.
- Scrolling either panel near the bottom settles both at the left Generate button and the bottom of the main studio.
- All intermediate controls remain reachable; scrolling is not restricted to only two positions.
- Focusing the prompt returns both panels to the top.
- Keyboard focus on the left Generate button brings both panels to the bottom.
- Mobile continues using natural page scrolling without nested synchronisation.
- Reduced-motion browser preferences disable animated scrolling.
