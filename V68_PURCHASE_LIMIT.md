# MixoLabs V68 — Temporary £15 Purchase Limit

Both adjustable payment options now accept amounts from £1.99 up to a maximum of £15:

- Repeatable one-time credit packs
- Monthly subscriptions with the existing 20% credit advantage

The £15 limit is enforced in both the browser interface and the server checkout endpoint. Changing a browser field cannot bypass it. At the current conservative 5p allowance, £15 provides approximately 208 one-time credits or 250 monthly credits.

This release includes all V67 mobile-navigation and V66 Early Access changes. Deploy it over the existing GitHub repository and preserve the current Render environment variables.
