# MixoLabs V67 — Mobile Navigation Fix

This release restores complete navigation on Android, iPhone, tablets and narrow browser windows.

At widths up to 980 pixels, a visible **Menu** button now appears beside the MixoLabs logo. It opens a touch-friendly full-height menu containing:

- Generator
- Gallery
- Favorites
- Tutorial
- Settings
- Log In / Create Account
- Appearance

The desktop navigation remains unchanged. This release also contains every V66 Early Access and safe-pricing change.

## Deployment

Upload the contents of this release to the existing GitHub repository, replacing matching files, and deploy the latest commit through the existing Render service. Preserve all current Render environment variables.

After deployment, open `mixolabs.art` on a phone or use a narrow browser window. Confirm that **Menu** appears beside the logo and that each menu item opens its corresponding MixoLabs area.
